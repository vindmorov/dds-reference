# DDS Beta — сценарий проверки

## Подготовка

1. Открыть `http://127.0.0.1:5173/` в новом приватном окне.
2. Использовать CSV с колонками `date,amount,description,counterparty`.
3. Для повторного входа использовать тот же браузер и не очищать localStorage.

## Основной сценарий

- Лендинг объясняет пользу продукта и ведёт к регистрации.
- Регистрация не пропускается без корректного email и пароля.
- Загрузка принимает `.csv`, `.xls`, `.xlsx` и отклоняет другие расширения.
- Вопросы о бизнесе требуют указать вид деятельности.
- Экран импорта показывает обработку и результат.
- В результате видны общее число операций, автоматически распределённые и требующие проверки.
- Пошаговая проверка позволяет подтвердить, изменить и пропустить операцию.
- Массовая проверка позволяет выбрать несколько строк и назначить категорию.
- Настройка категорий поддерживает потоки «Поступления» и «Списания».
- DDS показывает импортированный источник, период и динамические инсайты.
- Клик по инсайту открывает рекомендации и связанные категории.
- Действие из инсайта открывает проверку, создание статьи или beta-опрос.
- Опрос сохраняется после отправки.

## Негативные сценарии

- Файл неподдерживаемого типа.
- CSV без обязательной колонки суммы.
- Пустой CSV.
- Пропуск всех спорных операций.
- Обновление страницы после завершения импорта.
- Обновление страницы после перехода в DDS.
- Ширины 375px, 1024px и desktop.

## Критерий прохождения

Пользователь без помощи команды загружает свою выписку, понимает количество автоматически распределённых и спорных операций, находит категорию с заметной динамикой и отвечает на вопрос, куда обратить внимание.
